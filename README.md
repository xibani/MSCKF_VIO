# VIO-Pi

Odometría visual-inercial (MSCKF) en una Raspberry Pi 4 con cámara OV5647 e IMU MPU-6050,
escrita a mano en Python para aprender.

## Uso

Todo se ejecuta desde la raíz del proyecto, con el entorno virtual activo (atajo `svo`):

    python -m pytest                       # todos los tests
    python -m herramientas.info_entorno    # comprobar el entorno
